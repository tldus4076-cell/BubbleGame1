# Unity 6 버블슈터 Stage 1, 2, 3 기획서

## 1. 각 스테이지 목표

### Stage 1: 숲속 연습장

- 목표: 같은 색 버블 3개 이상을 맞춰서 모든 일반 버블을 없애기
- 목적: 조준, 발사, 3개 매칭 규칙을 배우는 스테이지
- 배경 이미지 예시: 밝은 숲, 맑은 하늘, 잔디밭

### Stage 2: 바닷가 도전

- 목표: 버블을 모두 없애기
- 목적: 더 많은 색과 조금 복잡한 배치를 연습하는 스테이지
- 배경 이미지 예시: 바다, 해변, 파도, 섬

### Stage 3: 동굴 결전

- 목표: 장애물을 피해 일반 버블을 모두 없애기
- 목적: 조준을 더 정확하게 하고 벽 튕기기를 사용하게 만드는 스테이지
- 배경 이미지 예시: 어두운 동굴, 보석 동굴, 용암 동굴

## 2. 색 종류 수

| Stage | 색 종류 수 | 예시 색 |
|---|---:|---|
| Stage 1 | 3개 | 빨강, 파랑, 노랑 |
| Stage 2 | 4개 | 빨강, 파랑, 노랑, 초록 |
| Stage 3 | 5개 | 빨강, 파랑, 노랑, 초록, 보라 |

## 3. 시작 배치 특징

### Stage 1

- 버블 줄 수: 4줄
- 배치 모양: 넓고 단순한 삼각형 모양
- 같은 색 버블이 가까이 모여 있음
- 장애물 없음

예시:

```text
빨 빨 파 파 노 노
 빨 빨 파 파 노
  빨 파 노 빨 파
   노 노 파 빨
```

### Stage 2

- 버블 줄 수: 5~6줄
- 배치 모양: 계단 모양 또는 지그재그 모양
- 같은 색 버블이 조금 떨어져 있음
- 빈칸이 조금 있음
- 벽 반사를 쓰면 좋은 위치가 있음

예시:

```text
빨 파 노 초 빨 파
 파 노 초 빨 파
  노 초 빨 파 노
   초 빨 빈 노 초
    빨 파 초 노
```

### Stage 3

- 버블 줄 수: 6~7줄
- 배치 모양: 좁은 길이 있는 복잡한 모양
- 같은 색 버블이 많이 흩어져 있음
- 장애물이 버블 사이에 있음
- 벽 튕기기를 사용해야 맞출 수 있는 곳이 있음

예시:

```text
빨 파 장 노 초 보
 파 장 노 초 보
  노 초 보 장 빨
   초 빈 장 파 노
    보 빨 초 파 장
     빨 노 보 초
```

`장`은 장애물입니다.

## 4. 실패 조건

| Stage | 제한 샷 수 | 제한 시간 | 실패 조건 |
|---|---:|---:|---|
| Stage 1 | 25발 | 90초 | 샷 수가 0, 시간이 0, 위험선 도달 |
| Stage 2 | 22발 | 75초 | 샷 수가 0, 시간이 0, 위험선 도달 |
| Stage 3 | 18발 | 60초 | 샷 수가 0, 시간이 0, 위험선 도달 |

## 5. 난이도 포인트

### Stage 1 쉬움

- 색 종류가 3개뿐입니다.
- 같은 색 버블이 가까이 있습니다.
- 제한 샷 수가 많습니다.
- 제한 시간이 넉넉합니다.
- 장애물이 없습니다.

### Stage 2 보통

- 색 종류가 4개로 늘어납니다.
- 버블 배치가 조금 복잡합니다.
- 제한 샷 수가 Stage 1보다 적습니다.
- 제한 시간이 Stage 1보다 짧습니다.
- 빈칸이 있어서 조준을 더 신중하게 해야 합니다.

### Stage 3 어려움

- 색 종류가 5개입니다.
- 같은 색 버블이 멀리 떨어져 있습니다.
- 제한 샷 수가 가장 적습니다.
- 제한 시간이 가장 짧습니다.
- 장애물이 있습니다.
- 벽 튕기기를 사용해야 하는 위치가 있습니다.

## 6. 초보자가 구현하기 쉬운 순서

1. Stage 1 배경 이미지를 넣습니다.
2. 빨강, 파랑, 노랑 버블 3종류를 만듭니다.
3. Stage 1 버블을 4줄로 단순하게 배치합니다.
4. 발사 횟수를 25발로 정합니다.
5. 제한 시간을 90초로 정합니다.
6. 같은 색 3개 이상이면 사라지는 기능을 만듭니다.
7. Stage 1 클리어와 실패를 확인합니다.
8. Stage 2 배경 이미지를 넣습니다.
9. 초록 버블을 추가합니다.
10. Stage 2 버블 배치를 5~6줄로 늘립니다.
11. 발사 횟수를 22발로 줄입니다.
12. 제한 시간을 75초로 줄입니다.
13. Stage 2 클리어와 실패를 확인합니다.
14. Stage 3 배경 이미지를 넣습니다.
15. 보라 버블을 추가합니다.
16. 장애물 버블을 만듭니다.
17. Stage 3 배치에 장애물을 넣습니다.
18. 발사 횟수를 18발로 줄입니다.
19. 제한 시간을 60초로 줄입니다.
20. Stage 3 클리어와 실패를 확인합니다.
