# Unity 6 2D 버블슈터 게임 기획서

## 1. 게임 한 줄 소개

알록달록한 버블을 쏘아서 같은 색 버블 3개 이상을 맞추고 없애는 2D 버블슈터 게임입니다.

## 2. 장르

2D 퍼즐 슈팅 게임입니다.

쉽게 말하면, 공을 조준해서 쏘고 같은 색을 맞추는 퍼즐 게임입니다.

## 3. 플레이어가 하는 핵심 행동

- 화면 아래의 발사대를 움직입니다.
- 원하는 방향으로 조준합니다.
- 버블을 발사합니다.
- 같은 색 버블을 3개 이상 모아 없앱니다.
- 모든 목표 버블을 없애면 다음 스테이지로 갑니다.

## 4. 조준과 발사 규칙

- 플레이어는 화면 아래에서 버블을 쏩니다.
- 마우스나 손가락으로 방향을 정합니다.
- 버튼을 누르거나 화면을 터치하면 버블이 발사됩니다.
- 버블은 벽에 닿으면 튕깁니다.
- 버블이 다른 버블에 닿으면 그 자리에 붙습니다.
- 한 번에 버블은 하나씩만 발사됩니다.

## 5. 매칭과 제거 규칙

- 같은 색 버블이 3개 이상 붙으면 사라집니다.
- 같은 색 버블이 2개만 붙으면 사라지지 않습니다.
- 버블이 사라진 뒤 천장과 연결되지 않은 버블은 아래로 떨어집니다.
- 버블을 많이 없앨수록 점수를 더 많이 얻습니다.

## 6. 클리어 조건

- 화면 위쪽의 일반 버블을 모두 없애면 클리어입니다.
- Stage 3에 장애물이 있어도 일반 버블을 모두 없애면 클리어할 수 있습니다.

## 7. 실패 조건

- 제한 샷 수를 모두 사용했는데 버블이 남아 있으면 실패입니다.
- 타이머가 0이 되었는데 클리어하지 못하면 실패입니다.
- 버블이 화면 아래 위험선까지 내려오면 실패입니다.

## 11. Unity 6 개발 순서 요약

1. 새 Unity 6 프로젝트를 2D로 만듭니다.
2. 배경 이미지를 넣고 화면에 배치합니다.
3. 타이머 숫자와 타이머 게이지를 만듭니다.
4. 점수 숫자를 만듭니다.
5. 발사대를 화면 아래에 만듭니다.
6. 버블 이미지를 만들거나 가져옵니다.
7. 현재 버블과 다음 버블을 표시합니다.
8. 마우스나 터치로 조준합니다.
9. 버블을 조준 방향으로 발사합니다.
10. 벽에 닿으면 튕기게 합니다.
11. 천장이나 다른 버블에 닿으면 붙게 합니다.
12. 같은 색 버블이 3개 이상인지 검사합니다.
13. 3개 이상이면 버블을 없앱니다.
14. 천장과 연결되지 않은 버블을 떨어뜨립니다.
15. 점수와 남은 발사 횟수를 UI에 표시합니다.
16. Stage 1, Stage 2, Stage 3 데이터를 만듭니다.
17. 클리어 화면과 실패 화면을 만듭니다.
18. 직접 플레이하면서 너무 쉽거나 어려운 부분을 고칩니다.
